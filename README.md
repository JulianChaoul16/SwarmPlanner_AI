## Run the dashboard

Install dependencies and launch the Streamlit app from the project directory:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Set `OPENAI_API_KEY` in your local `.env` file to generate missions. The warehouse
preview works without a key. Use the sidebar to set warehouse dimensions, robot
count, and speed, then submit an inspection request. Each robot has its own color;
assigned tasks and dashed assignment lines use the same color.

`app.py` connects the parser, mission service, optimizer, and Streamlit interface.
`visualizer.py` renders robots, tasks, obstacles, and assignment order. Positions
generated by the AI are illustrative. Travel uses straight-line distances; robot
motion and obstacle-aware routing are not yet simulated.
